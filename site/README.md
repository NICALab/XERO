# XERO project page

[View the project page](https://xero-viewer.pages.dev/project/)

Static HTML, CSS and JavaScript; no build step. Preview locally:

```bash
python -m http.server 8000 --directory site
```

To publish at `https://nicalab.github.io/XERO/`, choose **Settings → Pages → Source → GitHub Actions**, then run **Actions → Publish project page**. The viewer remains separate.
